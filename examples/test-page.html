Product example page

This page simulates a product website. One script embeds the widget in Shadow DOM, isolated from the host styles.

Getting started
  1. Start the API and worker, then create a product and web channel in the panel.
  2. Paste your channel public ID into the data-channel-id attribute at the bottom of this file.
  3. Serve this page over HTTP, allow its origin in the channel, and send a message.
  4. With translation configured, replies use your language and the panel shows Russian translations.
Verified identity

Your backend signs identity tokens using the channel secret. For integration testing, use the channel sample-token control in the panel (or POST /api/v1/admin/channels/:id/sample-token). 

SovaChat.identify("PASTE_SIGNED_TOKEN_HERE")
History recovery

Send a few messages and refresh the page. History should recover without duplicates. Disconnect in browser developer tools, send a message, then reconnect to check retry behavior.
